## Decisions and reasons

| Decision | Alternative | Reason / trade-off |
| --- | --- | --- |
| Nigerian JAMB Biology candidates | SS1 classroom cohort | Owner has better access; official syllabus available; recruitment assumptions still need validation. |
| Django + DRF | FastAPI | Editorial administration and integrated data management reduce assembly work; accept framework conventions. |
| Expo/TypeScript Android pilot | Bare native or two-platform release | Smaller setup/testing scope; installed build required later for App Links. |
| Manual AI drafts → human review → publication | Integrated generation/auto-publication | Preserve entertaining content idea while verifying accuracy; editorial work remains manual. |
| Four media formats now | Text/images first | Owner requires multimedia; accept preparation/playback effort and explicit file limits. |
| Data saver/caching | Full offline units and queued writes | Supports constrained connections without synchronization complexity. |
| Invited email-link login | Passwords or public registration | No remembered password; accept email delivery/domain/link configuration. |
| Likes now; sharing/uploads later | Social platform now | Measure expressed interest while limiting moderation scope. |
| Asynchronous challenges | Live battles | Avoid simultaneous connection/timing requirements. |
| Feature/documentation branches | Editing main | Owner requires isolated reviewable changes and preserved existing work. |
